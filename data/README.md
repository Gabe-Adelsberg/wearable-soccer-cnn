# Dataset Files

The original project used labeled CSV files collected from the wearable IMU during soccer drills.

Expected filenames from the preserved research code:

- `TrainingOne.csv`
- `LabelOne.csv`
- `TrainingTwo.csv`
- `LabelTwo.csv`
- `TrainingThree.csv`
- `LabelThree.csv`
- `testData.csv`
- `labelTest.csv`

The raw datasets are not currently included in this repository because they were not recovered from the archived project materials during repository reconstruction.

If the original data is recovered, it should be reviewed for privacy and consent before being published, since it may contain measurements collected from human participants.
